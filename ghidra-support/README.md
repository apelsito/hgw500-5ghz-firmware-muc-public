# Abrir la base de datos preservada

> Public source snapshot. [Scope, provenance and verification](docs/PUBLIC_SNAPSHOT.md).

Usar Ghidra 12.1.3 y Java 21. Instalar el ZIP de esta carpeta mediante
File → Install Extensions, reiniciar y crear un proyecto local.
Importar `../ghidra/quantenna-analysis.gzf` en ese proyecto.
El lenguaje es `ARCompact:LE:32:default`, compiler spec `default`.
El paquete exacto y su SHA-256 figuran en extension-receipt.json.

El código completo del módulo, pruebas, créditos y manifiesto están preservados en
[el padre](https://github.com/apelsito/hgw500-5ghz-firmwares-public/tree/main/ghidra-support)
desde el commit `41703a7bbac5a316e6e72381af67d5ee0e1d9d25`.
La extensión conserva Apache-2.0. El carrier OEM conserva su procedencia propia.
